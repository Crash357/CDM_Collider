# CDM Collider

Blender-Addon für **DayZ Collision / Geometry LOD**.

Eigenständiges Addon — nicht die alte DayZ-Suite. Passt zu CDM Architect und CDM P3D Studio.

Beispielszene in diesem Handbuch: **Cube** (normale Collision, Faces → AABB) und **Rock** (Convex Hull, V-HACD).

![Cube und Rock](../images/scene.png)

![N-Panel CDM Collider](../images/npanel.png)

## Schnellstart

1. [Installation](Installation.md) — ZIP aus dem Release, Blender 4.2+
2. N-Panel **CDM** → Abschnitt **CDM Collider**
3. Cube: Edit Mode → Faces wählen → **Faces → AABB** → **Merge → Geometry LOD**
4. Rock: Methode **V-HACD** → **1. Decompose** → **2. Merge Hull**
5. **DayZ Check** (max. 32 Components, 255 Verts)
